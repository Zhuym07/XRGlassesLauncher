# XR Desktop

把应用放到 XR 眼镜上，用手机作为低亮度触控板。

支持外屏桌面、应用切换、文字输入和截图。当前重点适配一加 13 / ColorOS 与 DP 外接 XR 眼镜，不保证所有设备和应用兼容。

**版本：0.4.7 · © 2026 Ckar**

## 开始使用

1. 从仓库 Releases 下载签名 APK 并安装，连接 XR 眼镜。
2. 在系统无障碍设置中启用 **XR Desktop**，日常使用保持开启即可。
3. 在应用「设置」中允许悬浮窗，让应用菜单显示在外屏当前应用上方。系统不支持时，会改用外屏菜单页面。
4. 在主页打开外屏桌面，选择应用，再点击 **进入触控板**。

移动、点击、滚动、文字输入和截图无需 Root。**外屏返回目前需要 Root**，首次使用时需授权；未实现 Shizuku。手机音量键不被占用。

> Release 与此前 Debug 版本的签名不同，不能直接覆盖安装。若卸载旧版，设置、收藏和草稿会被清空，请先自行保留需要的数据。

## 触控板怎么用

触控板默认全黑、低亮度。主体区域都可以操作，只有底部控制条和左上角退出区有单独用途。

| 区域 / 操作 | 功能 |
| --- | --- |
| 主体区域：单指移动 | 移动外屏光标 |
| 主体区域：轻点 / 连续轻点 | 点击 / 双击 |
| 主体区域：长按后移动 | 拖拽 |
| 主体区域：双指滑动 | 水平或垂直滚动 |
| 主体区域：四指同时轻点 | 截取外屏，可在设置中关闭 |
| 底部控制条左侧 1/3：轻点 | 打开外屏最近应用菜单 |
| 底部控制条右侧 2/3：轻点 | 返回外屏，需要 Root |
| 左上角隐藏区域：轻点 | 退出触控板，回到手机主页 |
| 手机系统返回键 | 退出触控板，不向外屏发送返回 |

底部控制条只响应短按，滑动、长按和多指触摸不会触发操作。沉浸模式下可先从屏幕边缘呼出系统导航，再使用手机返回键。

手机屏幕仍然点亮，以接收触摸；全黑界面不是物理息屏。退出触控板后恢复原窗口亮度。

## 应用与桌面

- **打开外屏桌面**：浏览全部应用、搜索、长按收藏，或查看最近应用。
- **最近应用菜单**：快速切换应用，优先使用外屏悬浮窗；关闭菜单不清除应用历史。
- **继续上次应用**：尝试在外屏重新打开上次应用。历史记录不代表应用仍在运行，也不保证恢复未保存内容。
- **外屏空闲时打开桌面**：启动时查询外屏实时窗口；未检测到应用才打开桌面。已有应用或状态不明时不自动切换。
- **重连后打开上次应用**：默认关闭。开启后尝试恢复上次应用，已有外屏应用则保留；不会自动进入手机触控板。

眼镜断开时会停止输入、关闭临时菜单并回到手机主页。重新连接后重新发现外屏，不固定使用旧的显示器 ID。

## 文字与截图

**输入文字**：先在外屏点击可编辑的输入框，再从手机主页打开「输入文字」并发送。目标输入框不支持时会提示失败并保留草稿。

**截取外屏**：从主页点击「截取外屏」，或在触控板主体区域四指轻点。截图保存到手机相册的 `Pictures/XRDesktop`，不需要相册读取权限。

外屏截图需要 Android 11 及以上和系统支持。安全窗口、禁止截图的应用或系统权限限制可能导致失败；不会自动改截手机屏幕。

## 设置

设置页提供收藏管理、图标大小、应用排序、指针与滚动灵敏度、四指截图、桌面启动与重连选项。支持 **简体中文 / English / 跟随系统**。

「清除最近记录」不会关闭应用或删除上次应用记录。「恢复默认设置」会清除收藏和最近记录，但保留上次应用、语言选择和文字草稿。详细状态可在「诊断」查看。

## 已知限制

- 光标是无障碍覆盖层，点击和滚动使用触摸手势，不是系统原生鼠标；不支持真正的悬停、右键或滚轮事件。
- ColorOS 可能在外屏断开时销毁第三方应用的任务。本应用不能保证保活，只能保留历史并尝试重新打开。
- 相机等锁定方向或不可调整大小的应用，仍可能出现黑边或比例异常。
- 系统可能拒绝外屏任务、悬浮窗或截图；遇到失败请检查权限，并在诊断页查看原因。
- 本应用不修改系统分区，不使用 LSPosed 或全局输入 Hook。

## 构建与验证

用 Android Studio 打开本目录，等待 Gradle Sync 完成后运行。需要 **Android SDK 36、JDK 21**；最低运行版本为 Android 10（API 29）。

Windows 终端：

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

依赖已缓存时可加 `--offline`。Debug APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

Release 构建与签名备份见 [发布指南](docs/RELEASING.md)，本版更新与发布前检查见 [0.4.7 发布说明](docs/releases/0.4.7.md)。不要提交或上传签名密钥、密码和本机配置。

自动化测试不能代替真机验收。正式发布前仍需验证外屏返回、文字输入、四指截图、拔插重连，以及至少 30 分钟的触控板稳定性。
