# XR Desktop 0.4.7

版权所有 © 2026 Ckar。

面向一加 13 / ColorOS 和 DP 外接 XR 眼镜的正式发布版本。最低 Android 10（API 29），具体功能依赖系统外屏任务与无障碍支持；尚不承诺所有设备与应用兼容。

## 主要功能

- 外屏独立桌面：搜索、收藏、最近应用、应用图标、网格密度和启动反馈。
- 手机低亮度全黑触控板：移动、点击、双击、拖拽、双指滚动与四指轻点截图。
- 外屏临时多任务菜单：最近 / 收藏 / 全部应用；优先悬浮窗，不支持时回退到外屏菜单 Activity。
- 主页 / 设置双 Tab、大尺寸操作按钮、简体中文与 English、关于和离线第三方许可。
- 手机文字输入面板，向外屏聚焦的可编辑节点发送文字；失败保留草稿。

## 本版修复

- 智能打开桌面使用实时外屏窗口，不再把断线前的应用历史当作仍运行的窗口。
- 外屏断线、新显示器 ID 和后续启动请求使旧验证回调失效，避免状态被过期结果覆盖。
- 触控板主体全部可移动；左上角为无文字退出热区。仅底部 96dp 为控制条：左 1/3 点击多任务，右 2/3 点击外屏返回，移动 / 长按 / 多指均取消。
- 手机系统返回退出触控板并恢复亮度，不占用音量键。
- 外屏返回严格使用指定显示器的可选 Root 命令，拒绝 / 超时不重复申请，不用会操作手机的无障碍全局返回兜底。
- 版权署名统一为 Ckar，提供独立 Release 签名配置和发布指南。
- 精简 README 与中英文界面文案，明确上次应用记录、实时外屏状态、权限和恢复设置的区别；本次文案更新不改变交互逻辑。

## 首次使用

连接眼镜，安装后启用 XR Desktop 无障碍服务。建议授予悬浮窗权限以使用不切换任务的菜单。移动、点击、滚动、文字输入和截图不强依赖 Root；**外屏返回目前需要 Root**，未实现 Shizuku。

截图保存至 `Pictures/XRDesktop`，通过 MediaStore 写入自身创建的图片，不需要相册读取权限。外屏截图需要 Android 11+ 和系统支持；安全窗口或系统拒绝时会失败，不会静默回退到手机截图。

## 已知限制

- 无障碍覆盖层光标与触摸手势不是原生系统鼠标，不支持真正悬停、右键或滚轮事件。
- ColorOS 断线时可能销毁第三方外屏 Activity，本应用只能保留历史并按设置尝试恢复，不能保证进程保活。
- 相机等锁定方向或不可调整大小的应用仍可能有黑边 / 比例异常。
- 本轮没有修改系统分区、使用 LSPosed 或新增全局输入 Hook。
- 自动化测试通过不代表真机完全验收；外屏返回效果、四指截图、断线重连和 30 分钟稳定性需在正式发布前验证。

## 安装 / 升级

下载 `XRDesktop-0.4.7-release.apk`，用同目录 SHA-256 文件校验。Debug 与 Release 的签名不同，不能直接覆盖；卸载会清空设置、收藏和草稿，操作前自行保留需要的数据。后续同签名 Release 可正常升级。

仓库目前为私有，发布附件仅对有仓库访问权限的用户可见。发布不会自动改变仓库可见性。
